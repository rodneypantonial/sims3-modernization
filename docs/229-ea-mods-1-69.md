## ErrorTrap on 1.69 (stamp patch)
Personal-use copy of NRaas's `NRaas_ErrorTrap_P169_V100` package (2026-11-02): ScriptCore S3SA `78CF6CF5304D0C4F` stamp `0.2.0.32` -> `1.0.0.18` (the 1.69.47 exe build string), so the start-up check no longer fires the docs/227 popup. [verified]
- Tool: `python tools/s3sa-stamp.py --set-stamp 1.0.0.18 IN OUT` (`python tools/s3sa-stamp.py` = self-check, `... file.package` lists stamps).
- Method: the S3SA resource was RefPack-compressed (comp `0xFFFF`, 235,992 B stored / 436,891 B raw). Decompressed, the 8 UTF-16 stamp chars at blob offset 5 replaced in place (4 bytes differ), stored uncompressed and appended to the file end; its index entry got the new offset, sizes and comp `0`. Header and old bytes untouched (dead space), file 533,353 -> 970,244 B.
- Check: 28 resources before and after; the 27 others identical in key, comp flag, sizes and bytes; the S3SA decompressed equals the new blob except those 4 bytes; ErrorTrap `489F97C6D1808FF7` (v1, no stamp) untouched.
- Installed 12:17 PHT as `Mods\Packages\NRaas_ErrorTrap.package` (source copy `Downloads\ts3-fixes\ea169\NRaas_ErrorTrap_P169_stamp1.0.0.18.package`), `scriptCache.package` deleted.
