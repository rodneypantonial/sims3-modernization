**Bug.** Design U phase 2 (`DeferFootprint2`), `DestroyPark` and `DestroyParkDx`, all on since v0.2.8, could lose EA's removal of an object's footprint from the lot map: docs/89 §16. v0.2.7 and older ship all three off.

**Reload.** Ghosts are saved in the `.nhd`, re-added on load, and removed by EA's pass `0x639B40` on a normal load; one survives only if a lot's routing load fails partway (docs/89 §17). `GhostSweep=2` is an ini change, the asi already has mode 2; it has work only after such a failed lot load.

**RemovalFirst.** A route not known unseen waits while a removal is queued: docs/89 §18. A rebuild of the hotfix head differs from `v0210e` only in the two link timestamps. `game-copy/ts3native.ini.v0210e` has the same keys and values as the repo ini; it lacks the comment and has the key in another place in `[Discourage]`.

**EA.** The EA address table has no row for 0x8297C0, 0x82C120, 0x833680, 0x9462D4, 0x94630A, so no EA build of this fix without mapping them first.
